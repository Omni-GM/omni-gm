Tool surface: four deep tools (D6)

Agents choose parameters well and similar tool names badly, so each tool covers one area and a parameter picks the operation. Unauthenticated callers see zero tools and get -32001 Unauthorized.

story_read     view: overview | schema | entities | entity
               kind?, nameContains?        (entities, max 25)
               entityId?, withHistory?     (entity; history = scene, transcript line, why, commit)

debrief        action: open | propose | drop | show | commit      → always returns { result, draft }
               open:    sessionId | newSession{adventureId, playedOn, scenes[]}, summary, shortSummary
               propose: debriefId, changes[{ scene, change, transcript{line, quote}, why }]
               drop:    debriefId, changeIds[]
               commit:  debriefId
               _meta.ui.resourceUri = ui://omni-gm/draft-debrief   (every call shows the Ledger)

story_correct  reason, changes[{ change, why, sceneId? }]           all or nothing, one commit
schema_change  reason, ops[ add_kind | add_property | retire_property | add_relationship_type ]
               separate on purpose: the client's tool-approval prompt is the deliberate step (D4)

change = create_entity{tempKey, kind, name, properties} | set_property{entity, key, value}
       | relate{type, from, to} | unrelate{type, from, to}          // entity = id or $tempKey

rejected: "mood" is not a property of npc. Allowed: playedAs, role, status.
          A new property needs a deliberate schema_change.

Open decision cards (round 2)

D9How is ADR 0001 updated for "cloud dev now"?

  • A. Amend ADR 0001 on main now: "starts on a Convex cloud dev deployment with a static token; real auth later", with today's date and the reason.
  • B. Write a new ADR 0002 that supersedes the "start local" part.
  • C. Leave it to the spec ticket.
I recommend A, as part of this ticket's resolution. Earlier tickets also wrote decisions straight to main, and one ADR stays one truth.

D10Which client renders the view, and how does it authenticate?

  • Only an MCP Apps host renders the Ledger: Claude Desktop or claude.ai, not Claude Code. Their connector UI doesn't take custom headers.
  • A. Static token through a local bridge: Claude Desktop's config runs bunx mcp-remote <url> --header "Authorization: Bearer …". It works today, but only on machines with that config.
  • B. WorkOS AuthKit OAuth now: auth.config.ts plus the gateway's OAuth discovery, and AuthKit's dynamic client registration for claude.ai. It works in every client, but it's the auth work ADR 0001 deferred.
  • C. Secret in the URL path, no auth header. Easiest, and the weakest.
I recommend A for the first real prep. B follows when a second client or person needs it, and the gateway makes it mostly configuration.

D1convex-mcp-gateway

The MCP endpoint is the Convex component, mounted in one HTTP action. Tools wrap internal functions. Verified: SDK client flow, _meta.ui on debrief, the text/html;profile=mcp-app resource, and an unauthenticated caller rejected. It's young (v2.1.1), so pin the version.

D2Structure as fixed tables

Campaign, adventure, session, and scene are tables, not graph entities.

D3Draft rows + current state + history log

Commits are one transaction. History is one index range per entity.

D4A separate schema_change tool

Schema commits go in the same log. Properties are retired, never deleted. No renames in v1.

D5Starter schema accepted as the start

The dry-run ticket trims or adds fields through schema commits.

D6Few deep tools

Four tools. A parameter picks the operation, which keeps context small and the choice easy.

D7Ledger view

Ledger with the session-note box. Drop is the only write; every other fix is said to the AI.

D8Convex cloud dev deployment now

Nothing to move later. This reopens ADR 0001's "start local" (D9).

LFrom earlier decisions

Generic entities constrained by definitions · no AI calls on the server · one debrief per session with scene, line, and why · corrections are small commits · domain functions internal.

Blast radius

  • What can break: a bad commit corrupts the story state. History keeps every before value, so a correction can restore it, and the draft gate sits in front.
  • New dependency: the gateway owns sessions, discovery, and audit in its own tables. If it stalls, the hand-written endpoint from round 1 (commit f2c8d3b) is about 100 lines.
  • Not exercised: Claude Desktop rendering the view; the cloud dev deployment (needs your convex login); OAuth.
  • Prototype shortcuts: the tools are internal actions composing queries and mutations, there are no returns validators (so no structuredContent), and the view is plain HTML rather than React and Tailwind.
