# PROTOTYPE: v2 briefing and section walk (throwaway)

Throwaway procedures for [Prototype: does a real briefing make prep feel like prep?](https://github.com/Omni-GM/omni-gm/issues/33).
They are drafts of the prompts a served skill would carry. Nothing here is wired into `convex/skills.ts`.

- [briefing.md](briefing.md): the one-page, plot-first briefing that opens prep.
- [section-walk.md](section-walk.md): one checklist section walked as facts, pitches, then the game master's turn.

The question they test: does prep that opens with a real briefing feel like prep, and do pitches help without generating the game master's prep for them?
Examples are invented. Real campaign output stays in the game master's private notes.
